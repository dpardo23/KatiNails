# Seguridad

## Reportar una vulnerabilidad

No abras un issue público. Usa el reporte privado de GitHub: en la pestaña
[Security](https://github.com/dpardo23/KatiNails/security), botón **Report a vulnerability**.

Incluye los pasos para reproducirla y su impacto.

## Alcance

El código de este repositorio y los sitios `katinails.com` y `app.katinails.com`.
