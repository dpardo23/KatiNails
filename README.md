# Katinails

Sistema de reservas y gestión del salón de uñas Katinails.

## Requisitos

- `git`, `mise`, `docker`, `gh`, `bw` y `jq`. Todo lo demás lo instala mise dentro del proyecto.

## Primeros pasos

```sh
source ./.entorno   # en cada terminal
mise install
pnpm install
pnpm run check
```
